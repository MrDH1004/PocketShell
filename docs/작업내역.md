### Mac · iPhone 브라우저 클라이언트 (v0.2.112)
- 앱 없이 브라우저로 사용: `https://<PC IP>:7380/` 접속 → 트레이 PIN 입력 → 토큰은 브라우저 localStorage에 저장
- 세션 목록(실행 중 · PC에서 연 콘솔 · 최근, 작업 중·입력 대기·끝남 배지), 새 세션(폴더 + AI CLI), 종료, 다시 열기, 기록 삭제, 연결 해제. 5초마다 갱신

- 검증: Playwright Chromium·WebKit(Safari 엔진) E2E 57/57 — 토큰 없이 페이지·자원 200, `/api` 401, 304, 잘못된 PIN 거절, 페어링, 새 세션, 영문·한글 입력 출력, 창 크기 → PC 세션 크기, 새로 고침 복원, 종료 → 최근, 기기 취소 → 페어링 화면, 390px 폭 가로 스크롤 없음, 키 바 ↑+Enter·Ctrl. 호스트 테스트 317/317. 실제 PC 0.2.112의 LAN 주소에서 두 엔진 모두 페이지 열림. 트레이 PIN 창 문구는 UIA로 확인
