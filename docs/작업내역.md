## 2026-11-09

### 외부 콘솔: PC 줄바꿈된 문단 이어붙여 폰 폭으로 재배치 (v0.2.38)
- Claude Code 등이 PC 폭에서 단어 단위로 접은 행을 한 줄로 이은 뒤 폰 폭으로 다시 접음 → 줄마다 짧은 꼬리("나눠떨어질", ", 끝에")가 남던 문제 해소
- 폰 줄바꿈은 띄어쓰기 우선, 이어지는 줄은 목록 기호(`- ` `●` `⎿`) 뒤 글자 열 또는 PC 연속 들여쓰기만큼 매달린 들여쓰기
- 상자·구분선·새 목록 항목·들여쓰기 감소 행은 잇지 않음, 긴 토큰(경로·URL)은 공백 없이 이음
- 핵심: `core/Reflow.kt` `Reflow.joins` / `Reflow.info` / `Reflow.layoutGroup`, `core/ConsoleHistory.kt` `pcCols`·`groupStart`, `TerminalActivity` Size 메시지에서 `history.pcCols` 설정
- 검증: `ReflowTest` 2건 추가(`pcWordWrappedRowsJoinAndRewrapWithHangingIndent`, `historyJoinsWrappedRowsWhenPcWidthKnown`), 단위 테스트·빌드 통과
- 한계: PC 폭 근처 길이의 서로 다른 두 줄이 연달아 오면 한 문단으로 잘못 이어질 수 있음

### 외부 콘솔: 플링 스크롤 위아래 대칭 (v0.2.39)
- 플링이 에뮬레이터 기록(`mTopRow`) 기준이라 아래로 튕기면 크게 점프, 위로 튕기면 관성 없음 → 폰 기록 기준 상대 플링으로 변경
- 핵심: `terminal-view/.../TerminalView.java` `onFling`
- 검증: 빌드 통과 (실기기 미확인)

### 외부 콘솔: 픽셀 단위 부드러운 스크롤·가장자리 탄성 (v0.2.40)
- 드래그·플링이 픽셀 단위로 이동(남는 줄 일부는 캔버스 오프셋), 손 떼면 0.16초 동안 가까운 줄에 정렬, 위/아래 끝에서 EdgeEffect 늘어남
- 핵심: `TerminalView` `remoteScrollPx` / `startRemoteFling` / `settleRemote` / `drawEdges` / `resetRemoteOffset`, `TerminalViewClient.canRemoteScroll`, `ConsoleHistory.maxScroll` 결과 캐시(`version` 키)
- 검증: 단위 테스트·빌드 통과 (실기기 미확인)
- 한계: 이동 중 화면 맨 위에 한 줄 이하 빈 띠가 잠깐 보일 수 있음

### PC 재시작 후에도 외부 콘솔 기록 유지 (v0.2.41)
- 호스트가 콘솔별 기록을 `%APPDATA%\PocketShell\external-scrollback\<pid>-<시작시각>.log`에 10초마다(변경 시)·종료 시 저장, 재시작 시 불러옴. 저장된 창을 직전 프레임으로 써서 꺼져 있던 동안 밀려난 줄도 추가
- 닫힌 콘솔의 파일은 삭제(실행 중 제거 + 호스트 시작 후 첫 목록 조회 때 정리)
- 폰: 호스트가 빈 기록을 보내면 폰이 가진 기록 유지 (`ConsoleHistory.replaceHistory`)
- 핵심: `host/src/Pkshell.Core/External/ConsoleScrollback.cs` (파일 생성자·`Save`·`DeleteFile`), `ExternalConsoles.cs` (`ScrollbackFile`, 저장 타이머, `PruneScrollbackFiles`), `HostServer.cs`
- 검증: 호스트 테스트 183개 통과(`ScrollbackSurvivesHostRestart` 추가), `psh update`로 0.2.40→0.2.41 적용, 업데이트 후 Claude 콘솔 2개의 저장 파일 생성 확인
- 한계: 업데이트 전 메모리 기록은 복구 불가. Claude/GPT 콘솔이거나 폰에서 연 콘솔만 기록됨
