# 세션 공유 매뉴얼

PocketShell 세션 하나를 다른 사람과 **같이 보거나 같이 입력**하는 기능입니다. PC 앱·폰 앱 모두 **v0.2.95 이상**이어야 합니다.

받는 사람은 공유받은 **그 세션 하나만** 쓸 수 있습니다. 내 PC의 다른 세션, 파일, 업데이트에는 접근할 수 없습니다.

---

## 1. 준비

| 항목 | 내용 |
| --- | --- |
| PC 앱 | v0.2.95 이상 (트레이 또는 `psh update`) |
| 내 폰 | PocketShell v0.2.95 이상, 이 PC와 페어링됨 |
| 상대 폰 | PocketShell 설치 (https://github.com/MrDH1004/PocketShell/releases/latest) |
| 네트워크 | 상대 폰이 **같은 Wi-Fi**에 있거나 **Tailscale**로 이 PC에 닿아야 함 |
| 세션 | 실행 중인 세션 또는 PC에서 연 콘솔(외부)만 공유 가능. '최근' 기록은 공유 불가 |

> 멀리 있는 사람과 공유하려면 Tailscale에서 이 PC를 상대에게 공유(Share machine)해 두세요.

---

## 2. 공유하기 (내 폰)

1. 세션 목록에서 공유할 세션을 **길게 누릅니다**.
2. **세션 공유**를 누릅니다.
3. 상대방이 할 수 있는 것을 고릅니다.
   - **같이 입력**: 화면도 보고 입력도 함
   - **보기만**: 화면만 봄
4. **공유 시간**을 고릅니다: 1시간 / 4시간 / 24시간. 시간은 상대방이 연결한 순간부터 셉니다.
5. **PIN 만들기**를 누릅니다.
6. 화면에 나온 내용을 상대방에게 알려 줍니다.
   - **PIN** (6자리, 10분 안에 한 사람만 사용)
   - **PC 주소** (LAN 주소, Tailscale 주소)
   - **지문** (`XXXX-XXXX-XXXX-XXXX`)
   - **QR 코드** (위 정보가 모두 들어 있음, v0.2.96+)
7. 옆에 있으면 상대가 QR을 찍게 하고, 떨어져 있으면 **보내기**를 누릅니다. 위 내용, 바로 연결 링크(`pocketshell://pair?...`), 앱 받는 링크가 메신저(카카오톡 등)로 그대로 전달됩니다.

여러 사람과 공유하려면 사람마다 PIN을 따로 만듭니다.

---

## 3. 공유받기 (상대 폰)

### QR 코드로 (가장 쉬움)
1. PocketShell 앱 → **PC 추가** → **QR 코드 스캔**.
2. 처음이면 카메라 권한을 허용합니다.
3. 공유하는 사람 화면의 QR을 찍으면 바로 연결되고 세션이 열립니다. 지문은 QR에 든 값과 자동으로 비교하며, 다르면 연결하지 않습니다.

### 링크로
- 메신저로 받은 `pocketshell://pair?...` 링크를 누르면 PocketShell이 열리고 주소·PIN이 채워집니다. **PIN으로 페어링**을 누르면 됩니다(지문 자동 확인). 메신저가 링크로 인식하지 않으면 아래 직접 입력을 쓰세요.

### 직접 입력
1. PocketShell 앱을 엽니다.
2. **PC 추가**를 누릅니다.
3. **PC 주소**에 받은 주소 하나를 입력합니다. 같은 Wi-Fi면 LAN 주소(예: `192.168.0.10`), 아니면 Tailscale 주소(`100.x.x.x`)를 씁니다. 포트가 붙어 있으면 그대로 입력합니다.
4. **PIN 6자리**를 입력하고 **PIN으로 페어링**을 누릅니다.
5. 지문 확인 창이 뜨면 받은 지문과 **정확히 같은지** 확인하고 **일치함**을 누릅니다. 다르면 취소하세요.
6. 공유받은 세션이 바로 열립니다.

이후에는 PC 목록에 별도 카드로 남습니다.

```
DESKTOP-XXXX
연결됨 · v0.2.95
공유받은 세션: flowdesk · 같이 입력 · 11/17 15:30까지
```

카드를 누르면 그 세션이 다시 열립니다.

## 4. 공유 중 화면

### 공유하는 쪽
- 세션 카드에 **공유 중 n**이 표시됩니다(연결한 사람 + 아직 안 쓴 PIN 수).

### 받는 쪽
| 모드 | 할 수 있는 것 | 안 되는 것 |
| --- | --- | --- |
| 같이 입력 | 화면 보기, 입력, 키 바, 음성 입력, 사진 첨부 | 다른 세션, 새 세션, PC 파일 탐색, 웹 보기, PC 업데이트 |
| 보기만 | 화면 보기, 스크롤, 글자 선택·복사·검색 | 위의 모든 것 + 입력 전부 (키보드·키 바·음성·사진 버튼 숨김) |

- 보기만이면 제목에 **· 보기 전용**이 붙고, 화면을 누르면 "입력할 수 없습니다" 안내가 나옵니다.
- 보기만 사용자는 PC 터미널 크기에 영향을 주지 않습니다.
- 같이 입력이면 화면 폭이 **마지막으로 입력한 사람**의 화면에 맞춰집니다. 두 사람이 번갈아 입력하면 줄바꿈이 바뀔 수 있습니다.

---

## 5. 공유 끝내기

### 직접 중지
- 세션을 길게 누름 → **공유 중지** → **공유 중지**.
- 연결한 사람은 **바로 끊기고**, 아직 쓰지 않은 PIN도 무효가 됩니다.

### 자동 종료
다음 중 하나가 되면 자동으로 끝납니다(최대 15초 안에 끊김).
- 정한 공유 시간이 지남
- 세션이 종료되거나 삭제됨
- PC에서 연 콘솔 창이 닫힘

받는 쪽에는 **"공유가 끝났습니다"**가 뜨고, PC 목록 카드는 **"공유 끝남 · 길게 눌러 목록에서 삭제하세요"**로 바뀝니다. 카드를 길게 눌러 **연결 해제**하면 목록에서 지워집니다.

## 6. PC에서 하기 (CLI)

```
psh list                                   세션 id 확인
psh share <id>                             같이 입력, 4시간
psh share <id> --view                      보기만
psh share <id> --view --hours 24           보기만, 24시간 (1~168)
psh shares                                 공유 현황 (누가, 모드, 끝나는 시각, 연결 여부)
psh unshare <id>                           그 세션 공유 중지
```

`psh share` 출력 예:
```
Share "flowdesk" (can type, 4 h after joining)

  PIN          365449   (one person, valid 10 minutes)
  PC address   192.168.18.49, 100.80.34.88  port 7380
  fingerprint  0889-3C1C-4468-9C03
```

## 7. 자주 묻는 것

| 증상 | 원인 · 해결 |
| --- | --- |
| PIN이 틀렸다고 나옴 | 10분이 지났거나 이미 누가 썼음. 새 PIN을 만드세요. 틀린 입력이 5번 쌓이면 열린 PIN이 모두 무효가 됩니다 |
| 연결이 안 됨 | 상대 폰이 이 PC에 닿지 않음. 같은 Wi-Fi인지, Tailscale 주소를 썼는지 확인 |
| "PC 앱이 0.2.95 이상이어야…" | PC 앱이 옛 버전. PC를 업데이트하세요 |
| "공유받은 세션이 지금 열려 있지 않습니다" | 세션이 끝났거나 콘솔이 닫힘. 공유한 사람에게 다시 요청 |
| 지문이 다름 / "QR 코드의 인증서 지문과 PC의 지문이 다릅니다" | 다른 PC가 응답했을 수 있음. 취소하고 공유한 사람에게 확인 |
| QR이 안 찍힘 | 화면 밝기를 올리거나 직접 입력 사용. "PocketShell 연결용 QR 코드가 아닙니다"면 다른 QR을 찍은 것 |
| 같은 PC를 이미 페어링했는데 공유도 받음 | 내 페어링과 공유받은 세션은 따로 저장되어 서로 덮어쓰지 않음 |

---

## 8. 보안

- 공유 PIN: 6자리, 10분, 1회용. 5번 틀리면 열린 PIN 모두 무효. 같은 IP에서 10분에 10번 넘게 실패하면 잠시 차단됩니다.
- 공유 토큰은 그 세션 하나에만 쓰입니다. 허용된 요청 밖은 PC가 403으로 거절합니다.
- 보기만 사용자가 보낸 입력은 PC가 버립니다(앱에서 막는 것과 별개로 서버에서도 차단).
- 공유받은 사람이 PC에 새 터미널 탭을 열게 하지 않습니다.
- PC 쪽 기록: `%APPDATA%\PocketShell\logs\host.log`에 PIN 발급, 참여, 중지, 종료가 `share:`로 남습니다.
